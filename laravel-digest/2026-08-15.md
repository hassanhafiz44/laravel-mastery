## Key Points

### Configuration

- By default, Laravel uses the bcrypt hashing driver when hashing data.
- However, several other hashing drivers are supported, including argon and argon2id .
- You may specify your application's hashing driver using the HASH_DRIVER environment variable.

### Hash Algorithm Verification

- To prevent hash algorithm manipulation, Laravel's Hash::check method will first verify the given hash was generated using the application's selected hashing algorithm.
- If the algorithms are different, a RuntimeException exception will be thrown.
- This is the expected behavior for most applications, where the hashing algorithm is not expected to change and different algorithms can be an indication of a malicious attack.
